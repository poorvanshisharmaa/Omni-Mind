# OmniMind Hub

UI Prompt:

Design a clean, professional web app called "OmniMind" — a multilingual meeting intelligence and translation platform for enterprise/BFSI users. Three main modes accessible via a sidebar: Meeting Intelligence, Document Intelligence, Universal Translator. Meeting Intelligence: an upload screen for audio files, then a results view with a diarized transcript (speaker-colored chat bubbles), a tabbed panel for Decisions / Action Items (table: task, owner, deadline, status) / Risks, and a "Provenance Log" tab showing timestamped decisions linked to audio playback clips with an "Export PDF" button. Document Intelligence: upload a PDF/DOCX, a language-pair selector (source/target dropdowns), a side-by-side original-vs-translated text view, and an audio player with chapter markers for narration playback. Universal Translator: a two-column "conversation" layout with language selectors per side, a mic button for live recording, waveform visualization while recording, and translated text/audio appearing inline. Global: a cross-lingual search bar in the top nav, dark/light mode toggle, and a minimal enterprise aesthetic (not playful) — think Linear or Notion, not a consumer app. Use a calm color palette (deep navy/slate primary, one accent color), clear typography hierarchy, and generous whitespace. Mobile-responsive is a bonus, not required for v1.
